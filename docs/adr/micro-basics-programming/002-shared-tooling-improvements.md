# ADR-002: 共通ツールの改善（図の指紋・公開名の検査）と、import * 方式の継続

日付: 2026-11-22

## ステータス

承認（ユーザーの承認: 2026-11-22）。実施済み。ただし、`import *` の見直しは、下記の理由で、継続とした。

## コンテキスト

全体レビュー（アーキテクト・テスター）で、次が指摘された。

1. 図の指紋が、線の座標・ラベル・軸の名前などしか見ず、軸の範囲や線種だけを変えても、画像が古いままになる
2. 連載ごとの `test/tools/test_lib_names.py` が複製され、内容がずれている
3. 練習問題の解答の実行が、前の章をすべて `import *` するため、全章の公開名を一意にする必要があり、名前が先着順になっている

## 決定

1. **図の指紋に、線種（`linestyle`）と軸の範囲（`xlim`・`ylim`）を含める。** 全連載の指紋を再生成する（画像のバイト列は変わらないことを確かめた）
2. **公開名の重複検査を `article_tools.lib_names` に移し**、3 連載のテストが、それを呼ぶ。`article_tools` に `py.typed` を置き、mypy が通るようにする
3. **解答の実行は、`import *` のまま継続する。** 章ごとの明示的な import に変えると、全連載・全章の解答の記事のコードに import を足す必要があり、記事の写経の負担が増える。代わりに、(a) 重複検査で、名前の衝突を機械で防ぐ、(b) 一般的すぎる名前を、題材が分かる名前にする（例: `externality_deadweight_loss`）、で補う。見直しは、第 2 版の候補として、計画書に記録する

## 影響

- 全連載の `figure_fingerprints.json` が更新される。以後、軸の範囲・線種の変更でも、図の再生成が求められる
- 名前の付け方に、章をまたぐ制約が残る（一意性）

## コンプライアンス

`apps/article-tools` のテスト、各連載の `test/tools`、`tox -e all` が通ること。
