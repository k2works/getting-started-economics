# ADR-002: 図の指紋の拡張と、変異確認ツールの共通化

日付: 2026-11-22

## ステータス

提案（ユーザーの承認: 「別の Unit で ADR を書いて実施」の方針に基づく）。実施済み。

## コンテキスト

1. 図の指紋は、線・棒・多角形・軸の範囲しか見ず、矢印の向き（`annotate`）・文字・塗り（`fill_between`）・タイトルを変えても、画像が古いままになる
2. 座標を小数 4 桁に丸めるため、対数目盛の小さい値（10⁻⁵ など）が 0 に潰れ、10⁻⁵ と 10⁻⁷ を区別できない
3. 変異確認のツールが、スクラッチにしかなく、版管理も再利用もできない

## 決定

1. **指紋に、`titles`・`texts`・`annotations`・`collections`・`suptitle` を、図にあるときだけ加える。** これらのない図の指紋は変わらない
2. **丸めは、絶対値 1e-3 未満で、かつ対数目盛の軸の座標だけ、有効数字で行う。** それ以外は、小数 4 桁のまま。理由: 全体を有効数字にすると、線形目盛で 0 になるはずの値の計算誤差（5.7e-15 など）が指紋に入り、OS や BLAS の版で揺れる。意味のある小さい値は、すべて対数目盛にあった
3. **変異確認を `article_tools.mutate` として取り込む。** 本物のリポジトリを書き換えず、一時複製で実行する。連鎖比較の全位置・`abs`・`max`/`min`・単項マイナス・0 の定数を扱う

## 影響

- 16 点の図の指紋を再生成した（画像のバイト列は、変わっていない）
- 指紋の対象外: 横棒グラフの幅、`fig.text`（suptitle 以外）、凡例の中身
- 別の OS での指紋の安定性は、CI で確かめる（特に第 5 章 `ch05-derivative-errors`）

## コンプライアンス

`apps/article-tools/tests`（指紋・変異の各テスト）と、6 連載の `render_figures --check`。
