# 経済学で出る数学プログラミング

経済学の教科書に出てくる数学（1 次・2 次関数、指数・対数、数列、微分、ベクトル、偏微分、行列、確率、積分、漸化式）を、Python のコードとテストで学ぶ記事シリーズです。数式は、目で追うだけでは「わかったつもり」になりやすい分野です。この連載では、**式を関数にして、手計算できる値をテストの期待値にし、数値とグラフで確かめます**。「公式で出した値」と「数値で出した値」が一致することを、自分のコードで確かめるので、わかったかどうかを、自分で判定できます。

ミクロ・マクロ・計量経済学の連載の**数学の土台**にあたります。理論の連載を読む前、または並行して読めます。目次の構成は、[経済学で出る数学 マインドマップ](<../経済学で出る数学 マインドマップ.md>) にまとめています。

各章の構成と、練習問題・到達チェックの使い方は、[この記事の読み方](how-to-read.md) を参照してください。

> 全 12 章（3 部）が公開されています（読者試行・全体レビューを経て、内容は更新されます）。各部の終わり（第 4・8・12 章）に、到達チェックがあります。

## この記事の読み方

### 対象読者と前提

- [経済学のためのプログラミング入門](../economics-programming/index.md)（以下、「第 1 シリーズ」）の第 1〜8 章（関数・pytest・リストと辞書・制御構文・モジュール・Matplotlib・乱数）を終えた方
- 高校数学の基礎（1 次関数・2 次関数・指数・対数）を、一度は学んだ方。忘れていても、第 1〜4 章で、思い出せます
- 経済学の教科書の数式（微分・偏微分・行列・積分）を、自分で動かして、納得したい方

NumPy は、前提にしません。必要な章（第 7 章）で、必要な分だけ、導入します（第 1〜6 章は、標準ライブラリだけで書きます）。SymPy・SciPy・pandas は、使いません（微分・積分は、公式と数値計算を、自分で実装して、突き合わせるのが目的です）。準備（uv のインストール）は、[第 1 シリーズの第 1 章](../economics-programming/01-preparation-and-first-test.md) を参照してください。

ミクロ・マクロの連載と題材が重なる章がありますが、各章は、**この連載だけで独立して読めます**。経済学としての意味（調整過程・課税の効果など）は、重なる連載の章へ案内します。

### 進め方

1. **予想する**: コードを見る前に、紙で、手計算の答えを予想します。**答えは書いてありません。**
2. **自分で書く**: `practice/` に、テストを先に書いて、実装を書きます（Red → Green → Refactor）
3. **答え合わせ**: 「プログラミング」の節の小節「予想の答え合わせ」で、予想の答えを、プログラムを動かして確かめます。完成形（`lib/` と `test/`）とも、見比べます
4. **練習問題・振り返り**: 条件を変えて試します。解答は、各章の練習問題の下に、折りたたんで置いてあります。先に自分で取り組んでから、開いてください
