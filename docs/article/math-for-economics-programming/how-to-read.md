# この記事の読み方

この記事は、経済学で使う数学を、Python の関数とテストで確かめながら、学ぶ構成です。全章は、同じ型で書いてあります。型を知っておくと、どの章でも、迷わずに進められます。

準備（uv のインストールなど）は、[第 1 シリーズの第 1 章](../economics-programming/01-preparation-and-first-test.md) の 1.2 節にあります。

## 章の型

どの章も、次の順で進みます。

| 節 | やること | ねらい |
| :--- | :--- | :--- |
| この章の地図 | 題材、使う機能、完成形のファイル、数学の式とコードの対応を、先に見る。図を 1 点、先に見る | 全体像を先に持つと、細部が既知の知識とつながる |
| 準備 | 実行コマンドと、期待する `N passed`（完成形の件数）を確かめる。`practice/` の使い方 | 環境が動くことを、先に確かめる |
| 予想する | コードを見る前に、手計算で、結果を予想する（紙に書く）。**答えは書いていない** | 先に自分で考えると、答えが長く記憶に残る |
| 考え方 | その章で使う数学の規則と、経済学での意味を学ぶ | 必要な知識を、必要なときに |
| プログラミング | `practice/` に、テストを先に書き、失敗を確かめ、最小の実装で通し、整える。最後に、**小節「予想の答え合わせ」**で、予想の答えを、プログラムで確かめる | 式をコードにする型を、手で覚える |
| 規則で言うと | その章の原則を 2〜3 個にまとめる。混同しやすい点を表で比べ、「このモデルが成り立たない場面」を確かめる | 個々の知識を、使える構造にする |
| 練習問題 | 想起・生成・多様・交互の 4 問。解答は、問題の下に折りたたんである | 本文を見ずに書く、条件を変える、前の章と混ぜる |
| 振り返り | うまくいった所、詰まった所、次に試すことを、ノートに書く | 自分の理解の穴を見つける |
| まとめ | その章で学んだことの確認と、次の章の予告 | — |

第 4 章（第 1 部）・第 8 章（第 2 部）・第 12 章（第 3 部）では、「規則で言うと」と「練習問題」の間に、**到達チェック**の節が入ります。

## 予想の答え合わせ

「予想する」の節には、**答えを書いていません。** 答えは、「プログラミング」の節の小節「予想の答え合わせ」で、**スクリプトを動かした出力**として示します。スクリプトは、その章の関数を呼ぶだけの短いものです。まず自分の予想を紙に書き、そのあとで、出力と見比べてください。

## 公式と数値の 2 つの答え

数学の章（微分・積分・漸化式・行列）では、**公式で出した値**と、**数値計算で出した値**の、2 つを実装して、一致を確かめます。教科書の公式を、そのまま信じるのでなく、自分のコードで確かめるためです。一致しないときは、公式の使い方か、数値計算の刻み幅・分割数を、疑います。

## 練習問題と解答

| 種類 | 内容 |
| :--- | :--- |
| 想起 | 本文を閉じて、その章の関数やテストを、自分で書く |
| 生成 | 解説を見る前に、新しい関数を、テストから書く |
| 多様 | 数値や式（パラメーター）を変えて、結果がどう変わるかを、先に予想してから確かめる |
| 交互 | 前の章の道具や、第 1 シリーズの内容と、組み合わせる |

解答（コードと手計算の答え）は、各章の練習問題の下に、折りたたんであります。**先に自分で取り組んでから、開いてください。**

- 計算は、各章の `lib/` の関数を呼びます。式を、ノートブックの中で、書き直してはいません。**写経は不要**です。読んで、動かして、「試してみよう」の数字を、確かめてください
- 乱数を使う章（第 9・10・11 章）は、種（`seed`）を Parameters に置いています。種を変えると、結果が変わります
- 実行結果は、ノートブックに保存していません。開くたびに、実行して確かめます

## 記号について {#symbols}

数学の記号は、章によって、同じ文字が別の意味になります。章を読むときは、**その章の「数学の式とコードの対応」の表**を、基準にしてください。意味が変わる章には、表の下に、注記があります。

### 全章に共通する記号

| 記号 | 意味 |
| :--- | :--- |
| p | 価格。グラフでは、縦軸 |
| q | 数量。グラフでは、横軸 |
| p\*・q\* | 均衡の価格・数量 |

### 第 1 章の記号（ほかの章では、別の意味になることがあります）

| 記号 | 第 1 章での意味 |
| :--- | :--- |
| a・b | 需要 q = a − b·p の係数（a: 価格 0 のときの需要量、b: 価格が 1 上がったときの需要量の減少） |
| c・d | 供給 q = c + d·p の係数 |

### 章で意味が変わる文字

同じ文字でも、章によって意味が違います。**必ず、その章の「数学の式とコードの対応」の表を、基準にしてください。**

| 文字 | 意味と、使う章 |
| :--- | :--- |
| a・b | 第 1 章: 需要の係数。第 2 章: 逆需要 P = a − b·Q と、2 次関数の係数。第 4 章: 初項（a）。第 8 章: コブ・ダグラスの分配率（a）。第 12 章: 漸化式の係数 |
| c・d | 第 1 章: 供給の係数。第 12 章: 消費（c\*） |
| n | 第 2 章: 企業の数。第 3 章: 年数。第 11 章: 入札者の数。第 12 章: 人口成長率（発展） |
| k | 第 3 章: 倍率。第 8 章: 同次の次数。第 11 章: 順位。第 12 章: 資本 |
| g | 第 6 章: 成長率。第 12 章: 技術進歩（発展） |
| p | 価格。第 10 章: 確率 P(A) |
| q | 数量。第 7 章: 状態価格（証券の価格） |
| m | 第 3 章: 年に複利を計算する回数。第 7・9 章: 所得 |
| r | 利子率・割引率（第 3・4・11 章など） |

章が進むと、記号が増えます。新しい記号は、その章の表で、定義します。

## この連載の約束（実装の方針）

- **NaN・無限大は、扱いません。** 教材なので、全関数に検証は入れません。入力の検証は、「その章の式が意味を持つ条件」（傾きが正、確率が 0〜1 など）に、絞ります
- **許容誤差**: 数値計算の結果（微分・積分・シミュレーション）を比べるときは、**相対的な誤差**（値の大きさに対する割合）を使います。数え上げ・分数（`Fraction`）の結果は、**厳密に**比べます。許容誤差の値は、章ごとに、根拠をコメントに書きます
- **図は、英語のラベルで描きます**（Matplotlib の日本語フォントの設定を避けるため）。本文と alt は、日本語です
- **「何も見ずに」書く課題（到達チェック）には、ヒントとして、関数の名前を、示すことがあります**（引数や係数の並びは、示さないか、必要最小限）
