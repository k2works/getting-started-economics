# この記事の読み方

この記事は、マクロ経済学のモデルとデータ分析を、Python の関数とテストで確かめながら、学ぶ構成です。全章は、同じ型で書いてあります。型を知っておくと、どの章でも、迷わずに進められます。[第 1 シリーズ](../economics-programming/how-to-read.md)と、同じ型です。

準備（uv のインストールなど）は、[第 1 シリーズの第 1 章](../economics-programming/01-preparation-and-first-test.md) の 1.2 節にあります。

## 章の型

どの章も、次の順で進みます。

| 節 | やること | ねらい |
| :--- | :--- | :--- |
| この章の地図 | 題材、使う機能、完成形のファイル、経済学の式とコードの対応を、先に見る | 全体像を先に持つと、細部が既知の知識とつながる |
| 予想する | コードを見る前に、手計算で、結果を予想する（紙に書く） | 先に自分で考えると、答えが長く記憶に残る |
| 概念の説明 | その章で使う経済学の用語と、データ・ライブラリの機能を学ぶ | 必要な知識を、必要なときに |
| プログラミング | `practice/` に、テストを先に書き、失敗を確かめ、最小の実装で通し、整える | 式をコードにする型を、手で覚える |
| 規則で言うと | その章の原則を 2〜3 個にまとめる。混同しやすい点を表で比べ、「このモデルが成り立たない場面」を確かめる | 個々の知識を、使える構造にする |
| 練習問題 | 想起・生成・多様・交互の 4 問。解答は、問題の下に折りたたんである | 本文を見ずに書く、条件を変える、前の章と混ぜる |
| 振り返り | うまくいった所、詰まった所、次に試すことを、ノートに書く | 自分の理解の穴を見つける |
| まとめ | その章で学んだことの確認と、次の章の予告 | — |

## 練習問題と解答

| 種類 | 内容 |
| :--- | :--- |
| 想起 | 本文を閉じて、その章の関数を、自分で書く |
| 生成 | 解説を見る前に、新しい関数を、テストから書く |
| 多様 | 数値や式（パラメーター）を変えて、結果がどう変わるかを、先に予想してから確かめる |
| 交互 | 前の章の道具や、第 1 シリーズの内容と、組み合わせる |

解答（コードと手計算の答え）は、各章の練習問題の下に、折りたたんであります。**先に自分で取り組んでから、開いてください。**

## 到達チェック

第 1 部（第 7 章）、第 2 部（第 12 章）、第 3 部（第 14 章）、第 4 部（第 18 章）の終わりに、「到達チェック」があります（第 1 部は、第 7 章に掲載済みです）。何も見ずに、できるかどうかを、自分で確かめるものです（第 1 シリーズと同じ使い方です）。

## 架空のデータについて

この記事のデータ（`data/` の CSV）は、**架空**です。実在の国や年の統計ではありません。構造だけを、実際の統計（Penn World Table、内閣府の国民経済計算など）にそろえてあります。実際の統計で試す手順は、各部の終わりにあります。

## 記号について {#symbols}

経済学の記号は、分野によって、同じ文字が別の意味になります。章を読むときは、**その章の「式とコードの対応」の表**を、基準にしてください。意味が変わる章には、表の下に、注記があります。この表は、章を足すたびに更新します。

### 全章に共通する記号

| 記号 | 意味 |
| :--- | :--- |
| y | 労働者 1 人当たりの所得（GDP） |
| k | 労働者 1 人当たりの物的資本 |
| h | 人的資本（労働者の技能の水準） |
| A | 全要素生産性（TFP） |
| α | 資本分配率（生産関数 y = A·k^α·h^(1−α) の指数） |
| ln | 自然対数 |
| g | 成長率（% / 年。対数の差を年数で割った値。第 2 章） |
| s・δ | 貯蓄率・減耗率（第 5 章） |
| λ | 収束の速さ。第 5 章は 1 期当たり（λ = (1 − α)·δ）、第 6 章は 1 年当たりの連続時間 |
| x* | 差分方程式の定常状態（第 4 章）。資本の定常状態は k*（第 5 章） |

### 章によって意味が変わる記号

| 記号 | 意味（章） |
| :--- | :--- |
| a・b | 回帰の係数（第 3 章）／需要曲線の切片・傾き（第 1 シリーズ） |
| y | 労働者 1 人当たりの所得（第 1・2 章）／回帰の被説明変数（第 3 章。第 3 章の発展会計では、対数の所得） |
| X・β | 回帰の説明変数の行列・係数（第 3 章） |
| ρ | AR(1) の係数（持続性。第 8 章） |
| σ | ショックの標準偏差（第 8 章） |
| λ（HP フィルター） | 平滑化の強さ（第 9 章。四半期で 1600。コードの引数名は smoothing）。収束の速さ λ（第 5・6 章）とは別 |
| β | 収斂の回帰の傾き（第 6 章）／ペン効果の回帰の傾き（第 7 章）／回帰の係数（第 3 章） |
| e | 為替レート（自国通貨 / ドル。第 7 章）。第 12 章は、自国通貨 / 外国通貨 |
| μ・π | 貨幣の伸び率・物価上昇率（% / 年。第 11 章）。π は、第 10 章のフィリップス曲線の物価上昇率と同じ意味 |
| q | 実質為替レート q = e × P* ÷ P（第 12 章） |
| y・p | 産出量・物価水準の、トレンドからの乖離（%。第 13・14 章）。第 1〜3 章の y（所得）とは別 |
| a・c・h | AS 曲線の傾き・AD 曲線の傾き・物価の持続性 h = 1 ÷ (1 + a·c)（第 13・14 章）。第 4 章の a・b とは別 |
| u・v | 需要ショック・供給ショック（第 13・14 章）。第 15 章は、u・v・e が、IS・MP・PC 曲線へのショック。第 18 章の v は、TFP のショック（A' = A^ρ·e^v） |
| 小文字の a・k・c・y・i・r・w・l（第 18 章） | 大文字の変数（A・K・C・Y・I・R・W・L）の、定常状態からの、対数の乖離（%）。第 15 章の r・i（水準）とは別。r は、利子率そのものの相対的な変化率で、ポイントの差ではない |
| π・i・r・φ | インフレ率・名目利子率・実質利子率・インフレ率の差分方程式の係数 φ = (1 + a·d) ÷ (1 + a·b·c + a·d)（第 15 章）。第 11 章の π（物価上昇率）と同じ意味 |
| a・b・c・d（IS-MP-PC） | IS 曲線の傾き・フィリップス曲線の傾き・MP 曲線のインフレ率・産出量への反応（第 15 章）。第 13 章の a・c（AS・AD 曲線の傾き）とは別 |
| x̂・A・B・M（対数線形近似） | 定常状態からの乖離率 x̂ = ln(x ÷ x*)、均衡条件の微分の行列 A・B、遷移行列 M = −A⁻¹B（第 17 章）。第 15 章の A・B（行列）とは別 |
| β・θ・m・L・R・W（RBC） | 割引因子・危険回避度・余暇の重み・労働時間・実質利子率・実質賃金（第 18 章）。第 16 章の H（総労働時間）は、第 18 章では L と書く |
| A・B・H・s・δ（確率的ソロー） | TFP の変動・TFP のトレンド・総労働時間・貯蓄率・減耗率（第 16 章）。a・y・k・h は、TFP・GDP・資本・労働時間のトレンドからの乖離（%） |
| a・b | 差分方程式の係数 x(t+1) = a·x(t) + b（第 4 章）。蜘蛛の巣モデルの需要・供給の係数は、a₀・b₀・c・d |
| A | 全要素生産性（第 1・2 章）／技術水準（第 5 章。同じ意味）|
| n・k | 観測数・係数の数（第 3 章）／k は、物的資本と同じ文字（第 1・2 章）なので、章の表を確認する |
