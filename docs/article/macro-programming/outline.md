### linearsolve の調査結果

元の記事は、第 14・15 章（RBC）で `linearsolve` を使っています。導入を決める前に、隔離した環境で確かめました（2026-11-19）。

| 確認したこと | 結果 |
| :--- | :--- |
| バージョンと Python 3.12 での `import` | `linearsolve` 3.6.3 が、Python 3.12 で、`import` できた（numpy 2.5.5、pandas 3.1.1、scipy 1.18.1、statsmodels 0.15.0 の環境） |
| 依存パッケージの宣言 | **宣言がない**（メタデータの依存が空）。`linearsolve` だけを入れると、`numpy` がなくて、`import` に失敗する。`statsmodels` も必要（内部で、数値微分に使っている）。`numpy`・`pandas`・`scipy`・`statsmodels` を、こちらで明示する必要がある |
| 型の情報 | 確認していない。mypy では、`ignore_missing_imports` が必要になる見込み |
| ソロー・モデルの対数線形近似（Bolt 0 で確認） | **pandas 3.1.1（このプロジェクトの版）では失敗する**: `log_linear_approximation` が `np.log(self.ss).ravel()` を呼ぶが、`Series.ravel` は pandas 3 で削除された。**pandas 2.3.3 では動き**（`FutureWarning` が出る）、α = 0.5、s = 0.2、δ = 0.05 の例で、遷移係数 p = 0.975 を得て、第 5 章の 1 − λ = 1 − (1 − α)·δ = 0.975 と**一致した** |
| 結論 | **自作する**（承認事項 5 の「使えなければ自作する」）。pandas を 2 系に固定すると、第 1 シリーズ・ほかの章の前提（pandas ≥ 3.1.1）と食い違うため。第 17 章で、数値微分による対数線形近似と、線形の動学の解法（行列）を自作し、第 18 章の RBC に使う。`linearsolve` の結果（p = 0.975）は、自作の実装の照合値にできる |
