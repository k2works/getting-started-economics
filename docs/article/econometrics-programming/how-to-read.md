# この記事の読み方

この記事は、計量経済学の推定量と検定を、Python の関数とテストで確かめながら、学ぶ構成です。全章は、同じ型で書いてあります。型を知っておくと、どの章でも、迷わずに進められます。[第 1 シリーズ](../economics-programming/how-to-read.md)と、同じ型です。

準備（uv のインストールなど）は、[第 1 シリーズの第 1 章](../economics-programming/01-preparation-and-first-test.md) の 1.2 節にあります。

## 章の型

どの章も、次の順で進みます。

| 節 | やること | ねらい |
| :--- | :--- | :--- |
| この章の地図 | 題材、使う機能、完成形のファイル、式とコードの対応を、先に見る | 全体像を先に持つと、細部が既知の知識とつながる |
| 予想する | コードを見る前に、手計算で、結果を予想する（紙に書く） | 先に自分で考えると、答えが長く記憶に残る |

## 練習問題と解答

| 種類 | 内容 |
| :--- | :--- |
| 想起 | 本文を閉じて、その章の関数を、自分で書く |
| 生成 | 解説を見る前に、新しい関数を、テストから書く |
| 多様 | 数値や真の値（パラメーター）を変えて、結果がどう変わるかを、先に予想してから確かめる |
| 交互 | 前の章の道具や、第 1 シリーズの内容と、組み合わせる |

解答（コードと手計算の答え）は、各章の練習問題の下に、折りたたんであります。**先に自分で取り組んでから、開いてください。**

## 乱数のデータについて

この記事のデータは、主に、**乱数で作った**ものです。母集団の式（真の係数）を、自分で決めて、データを作ります。真の値を知っているので、推定量が、真の値に近づくか、どちらに偏るかを、確かめられます。実際のデータで試す手順は、各部の終わりにあります。

## 乱数のテストについて

乱数を使うテストは、次の約束で書きます。

| 約束 | 内容 |
| :--- | :--- |
| 乱数の生成器を、引数で渡す | `rng: np.random.Generator` を引数にする。関数の中で、種を決めない |
| 種を固定する | テストの中で `np.random.default_rng(0)` のように、種を決める。毎回、同じ結果になる |
| 許容誤差を、理論から決める | 例: 標準誤差の 4 倍以内。許容誤差が、広すぎると、テストが何も確かめない。狭すぎると、種を変えただけで壊れる |
| 恒等式・照合を、先に置く | 乱数に頼らない確かめ方（ちょうど成り立つ関係、ライブラリとの一致）を、中心にする |

## 記号について {#symbols}

計量経済学の記号は、分野（マクロ・ミクロ）によって、同じ文字が別の意味になります。章を読むときは、**その章の「式とコードの対応」の表**を、基準にしてください。意味が変わる章には、表の下に、注記があります。この表は、章を足すたびに更新します。

### 全章に共通する記号

| 記号 | 意味 |
| :--- | :--- |
| n | 観測値の数（標本の大きさ） |
| x̄ | 標本平均 |
| s²・s_xy・r | 不偏分散・標本共分散・標本相関係数（第 1 章） |
| SE | 標準誤差 |
| Φ | 標準正規分布の分布関数（第 1 章） |
| α̂・β̂ | 切片・傾きの推定値（第 2 章） |
| e・h | 残差・てこ比（第 2・4 章） |
| k | 定数項を含む係数の数（第 3 章以降）。マクロの記事では、物的資本 |
| S・K | 歪度・尖度（第 6 章） |
| q | 制約の数（第 5・6 章） |
| δ・γ | ダミー変数の係数・交差項の係数（第 7 章）。第 9 章の δ は、処置の効果（DiD） |
| HC0〜HC3 | 頑健な標準誤差の種類（第 8 章） |
| a_i | 個人 i ごとの観測されない効果（第 9・10 章） |
| N・T | 個人の数・期数（第 10 章） |
| θ | ランダム効果の準差分の係数（第 10 章） |
| H | Hausman 検定の統計量（第 10 章） |

### 章によって意味が変わる記号

この表は、章を足すたびに、更新します。次の記号は、後の章で使い、他のシリーズとは意味が違います。

| 記号 | この記事での意味 | 他のシリーズでの意味 |
| :--- | :--- | :--- |
| α | 回帰の切片（定数項）の係数 | マクロ: 資本分配率 |
| ρ | 相関係数 | マクロ: AR(1) の持続性 |
| λ | 逆ミルズ比（第 16 章） | マクロ: 収束の速さ |
| β | 回帰の係数 | マクロ: 収斂の回帰の傾き |
| u・ε | 誤差項（母集団）。残差は、û・e | マクロ: ショック |
