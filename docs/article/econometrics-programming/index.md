## この記事の読み方

### 対象読者と前提

- [第 1 シリーズ](../economics-programming/index.md)を終えた方、または、同等の Python（関数・pytest・NumPy・pandas・Matplotlib・乱数）の経験がある方
- 統計学の初歩（平均・分散・確率分布）を学んだ方。計量経済学を学んでいる、または、これから学ぶ方

Python の基礎は、繰り返しません。準備（uv のインストール）は、[第 1 シリーズの第 1 章](../economics-programming/01-preparation-and-first-test.md) の 1.2 節にあります。

### 進め方

第 1 シリーズと同じです。

1. **予想する**: コードを見る前に、紙で、手計算の答えを予想します
2. **自分で書く**: `practice/` に、テストを先に書いて、実装を書きます（Red → Green → Refactor）
3. **答え合わせ**: 完成形（`lib/` と `test/`）と見比べます
4. **練習問題・振り返り**: 条件を変えて試します。解答は、各章の練習問題の下に、折りたたんで置いてあります。先に自分で取り組んでから、開いてください

### 3 つの確かめ方

この記事では、推定量を、次の 3 つで確かめます。

| 確かめ方 | 内容 |
| :--- | :--- |
| 恒等式 | 「固定効果推定 = ダミー変数推定」のように、**ちょうど成り立つ関係**をテストにする。乱数に頼らない |
| 照合 | 自分で書いた推定量が、`statsmodels`・`linearmodels` の結果と一致するか確かめる |
| シミュレーション | 真の値を決めて、乱数でデータを作り、推定量の平均・ばらつき・バイアスを、真の値と比べる。乱数の種を固定する |
