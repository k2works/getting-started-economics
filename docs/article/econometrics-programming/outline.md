## 概要

「計量経済学のためのプログラミング」は、学部レベルの計量経済学（回帰分析、推論、パネル・データ、操作変数法、離散選択・制限従属変数モデル）を、**推定量を自分で書き、シミュレーションと恒等式で確かめる**ことで学ぶ記事です。[経済学のためのプログラミング入門](../economics-programming/index.md)（以下、「第 1 シリーズ」）の続編で、[マクロ経済学のためのプログラミング（中級＋）](../macro-programming/index.md)（以下、「第 2 シリーズ」）と並ぶ、**第 3 シリーズ**です。同じ構成（章の型・TDD・練習問題・到達チェック）で書きます。

第 2 シリーズが「マクロのデータと動学モデルを、数値で確かめる」記事なのに対して、この記事は次の 3 つを加えます。

| 加えるもの | 内容 |
| :--- | :--- |
| 推定量を、式から書く | OLS・頑健な標準誤差・固定効果・操作変数法（2SLS）・ロジット／プロビット・トービット・ヘックマンの 2 段階推定を、行列と最尤法で書き、`statsmodels` と `linearmodels` の結果と照合する |
| 真の値を知っているデータ | 母集団の式（真の係数）を自分で決め、乱数でデータを作る。推定量の性質（不偏性・一致性・バイアス・検定の大きさ）を、真の値と比べて確かめる |
| 恒等式による検証 | 「固定効果推定 = ダミー変数推定」「単回帰の傾き = 偏りを除いた回帰の傾き（FWL）」など、**ちょうど成り立つ関係**を、テストにする。乱数に頼らないので、テストが安定する |

## 章別計画

各章で、先にテストを書く関数と、テストの期待値です。期待値は、手計算で確かめた**例**です（実装前の計画値なので、実装時に、必ず、実行して再確認します。第 2 シリーズで、推測した値を、実測値に直した経験があります）。

共通の例（第 2・5・8 章で使う小さなデータ）: x = [1, 2, 3, 4]、y = [2, 4, 5, 9]。手計算で、平均は x が 2.5、y が 5。傾き = S_xy ÷ S_xx = 11 ÷ 5 = **2.2**、切片 = 5 − 2.2 × 2.5 = **−0.5**。当てはめ値は 1.7、3.9、6.1、8.3、残差は 0.3、0.1、−1.1、0.7（和は 0）。残差平方和 = 1.8、全平方和 = 26、決定係数 = 1 − 1.8 ÷ 26 ≈ **0.9308**。

つまずきの記録（読者も、同じ壁に当たるので、記事の第 10 章に書く）:

- 個人ごとに変わらない変数（例: `educ`）を、固定効果モデルに入れると、**固定効果に吸収されて**、`AbsorbingEffectError` になる。仕様どおりの動きで、バグではない（この調査で、実際に当たった）

**依存の分類の基準**: 実装（`lib/`）が使うものと、記事の本文で読者に `import` させるものは、本体の依存（`numpy`・`pandas`・`scipy`・`matplotlib`・`statsmodels`）。`statsmodels` は、`lib/` は使わないが、第 5 章以降の本文で、読者が結果を照合するために使う。テストだけが照合に使うものは、開発用（`linearmodels`。第 13 章の本文でも照合に使うが、`lib/` を動かすのに要らない）。実際のデータ（`wooldridge`）は、任意の依存グループ `realdata`。
