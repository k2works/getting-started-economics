# この記事の読み方

この記事は、教科書的なマクロ経済学の式とグラフを、Python の関数とテストで確かめながら、学ぶ構成です。全章は、同じ型で書いてあります。型を知っておくと、どの章でも、迷わずに進められます。

準備（uv のインストールなど）は、[第 1 シリーズの第 1 章](../economics-programming/01-preparation-and-first-test.md) の 1.2 節にあります。

## 章の型

どの章も、次の順で進みます。

| 節 | やること | ねらい |
| :--- | :--- | :--- |
| この章の地図 | 題材、使う機能、完成形のファイル、経済学の式とコードの対応を、先に見る。図を 1 点、先に見る | 全体像を先に持つと、細部が既知の知識とつながる |
| 予想する | コードを見る前に、手計算で、結果を予想する（紙に書く）。**答えは書いていない** | 先に自分で考えると、答えが長く記憶に残る |
| 概念の説明 | その章で使う経済学の用語と、ライブラリの機能を学ぶ | 必要な知識を、必要なときに |
| プログラミング | `practice/` に、テストを先に書き、失敗を確かめ、最小の実装で通し、整える。最後に、**小節「予想の答え合わせ」**で、予想の答えを、プログラムで確かめる | 式をコードにする型を、手で覚える |
| 規則で言うと | その章の原則を 2〜3 個にまとめる。混同しやすい点を表で比べ、「このモデルが成り立たない場面」を確かめる | 個々の知識を、使える構造にする |
| 練習問題 | 想起・生成・多様・交互の 4 問。解答は、問題の下に折りたたんである | 本文を見ずに書く、条件を変える、前の章と混ぜる |
| 振り返り | うまくいった所、詰まった所、次に試すことを、ノートに書く | 自分の理解の穴を見つける |
| まとめ | その章で学んだことの確認と、次の章の予告 | — |

## 予想の答え合わせ

「予想する」の節には、**答えを書いていません。** 答えは、「プログラミング」の節の小節「予想の答え合わせ」で、**スクリプトを動かした出力**として示します。スクリプトは、その章の関数を使い、出力は、実際に実行して得た値です（記事とコードのずれは、検査で確かめています）。自分の予想と、出力を比べて、ずれた理由を考えてください。

## 練習問題と解答

| 種類 | 内容 |
| :--- | :--- |
| 想起 | 本文を閉じて、その章の関数を、自分で書く |
| 生成 | 解説を見る前に、新しい関数を、テストから書く |
| 多様 | 数値や式（パラメーター）を変えて、結果がどう変わるかを、先に予想してから確かめる |
| 交互 | 前の章の道具や、第 1 シリーズの内容と、組み合わせる |

解答（コードと手計算の答え）は、各章の練習問題の下に、折りたたんであります。**先に自分で取り組んでから、開いてください。**

## 到達チェック

第 1 部（第 5 章）、第 2 部（第 9 章）、第 3 部（第 14 章）の終わりに、「到達チェック」があります。何も見ずに、できるかどうかを、自分で確かめる節です。できなかった項目は、戻る章が書いてあります。

## 架空のデータについて

この記事は、**実在の統計を使いません。** 手計算できる小さな例と、架空のデータ（`data/` の CSV）だけを使います。架空のデータは、実在の国や年の統計ではありません。実際の統計を使う分析は、[マクロ経済学のためのプログラミング（中級＋）](../macro-programming/index.md) や、[計量経済学のためのプログラミング](../econometrics-programming/index.md) で扱います。

## 記号について {#symbols}

経済学の記号は、分野によって、同じ文字が別の意味になります。章を読むときは、**その章の「式とコードの対応」の表**を、基準にしてください。意味が変わる章には、表の下に、注記があります。この表は、章を足すごとに、更新します。

### 全章に共通する記号

| 記号 | 意味 |
| :--- | :--- |
| GDP・GNI・NDP | 国内総生産・国民総所得・国内純生産（第 1 章） |
| Y | 国民所得（GDP。フロー。第 4 章以降） |
| C・I・G・X | 消費・投資・政府支出・純輸出（第 4 章。総需要 D = C + I + G + X） |
| c | 限界消費性向（0 以上 1 未満。第 4 章以降） |

### 章によって意味が変わる記号

| 記号 | 意味（章） |
| :--- | :--- |
| A | 投入係数の行列（第 2 章）／独立支出（第 4・5 章。均衡国民所得 Y = A ÷ (1 − c)） |
| I | 単位行列（第 2 章の (I − A)）／投資（第 4 章。総需要の I） |
| x・f | 産出（生産量）のベクトル・最終需要のベクトル（第 2 章。(I − A) x = f） |
| t・T | 比例税の税率 t（第 5 章）／定額税 T（第 4 章） |
| c | 限界消費性向（第 4 章以降）。第 1 章の成長会計の分配率（労働分配率・資本分配率）とは別 |
| 価格 p・数量 q | 物価指数の価格・数量（第 3 章。ラスパイレス・パーシェ）。第 4 章以降の記号とは無関係 |
| ギャップの符号 | 「完全雇用所得 − 均衡所得」で、**正がデフレギャップ、負がインフレギャップ**（第 5 章） |

## 完成形の使い方

サンプルコードには、各章の完成形が入っています（`lib/` と `test/`）。**答え合わせ用**です。自分のコードを、`practice/` に書いてから、見比べてください。
