### 章の型

全章を、同じ 8 節にそろえます。

| 節 | 内容 |
| :--- | :--- |
| この章の地図 | 題材・使う機能・完成形のファイル・式とコードの対応表。**図を 1 点、先に見せる** |
| 予想する | コードを見る前に、結果を予想する。**答えは書かない** |

| 規則で言うと | 原則 2〜3 個、混同しやすい対比の表（マインドマップの「混同注意」）、「このモデルが成り立たない場面」 |

### 落とし穴への対策

| 落とし穴 | 記事での対策 |
