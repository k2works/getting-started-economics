# この記事の読み方

この記事は、経済学のモデル（需要と供給、IS-LM、独占など）を、Python の関数にして、テストで確かめながら、プログラミングと経済学を同時に学ぶ構成です。全 15 章は、同じ型で書いてあります。型を知っておくと、どの章でも、迷わずに進められます。

準備（uv のインストールなど）は、[第 1 章](01-preparation-and-first-test.md) の 1.2 節にあります。

## 章の型

どの章も、次の順で進みます。

| 節 | やること | ねらい |
| :--- | :--- | :--- |
| この章の地図 | 題材、使う Python の機能、完成形のファイル、経済学の式とコードの対応を、先に見る | 全体像を先に持つと、細部が既知の知識とつながる |
| 予想する | コードを見る前に、手計算で、結果を予想する（紙に書く） | 先に自分で考えると、答えが長く記憶に残る |
| 概念の説明 | その章で使う Python の機能と、経済学の用語を学ぶ | 必要な知識を、必要なときに |
| プログラミング | `practice/` に、テストを先に書き、失敗を確かめ、最小の実装で通し、整える | 式をコードにする型を、手で覚える |
| 規則で言うと | その章の原則を 2〜3 個にまとめる。混同しやすい点を表で比べ、「このモデルが成り立たない場面」を確かめる | 個々の知識を、使える構造にする |
| 練習問題 | 想起・生成・多様・交互の 4 問。解答は、問題の下に折りたたんである | 本文を見ずに書く、条件を変える、前の章と混ぜる |
| 振り返り | うまくいった所、詰まった所、次に試すことを、ノートに書く | 自分の理解の穴を見つける |
| まとめ | その章で学んだことの確認と、次の章の予告 | — |

## 練習問題と解答

練習問題は、次の 4 種類です。

| 種類 | 内容 |
| :--- | :--- |
| 想起 | 本文を閉じて、その章の関数を、自分で書く |
| 生成 | 解説を見る前に、新しい関数を、テストから書く |
| 多様 | 数値や式を変えて、手計算と、テストで確かめる |
| 交互 | 前の章の道具と、組み合わせる |

解答（コードと手計算の答え）は、各章の練習問題の下に、折りたたんであります。**先に自分で取り組んでから、開いてください。** 開くと、答えが見えてしまうので、取り組む前には、開かないことをお勧めします。

## 到達チェック

第 1 部（第 6 章）、第 2 部（第 10 章）、第 3 部（第 12 章）、第 4 部（第 15 章）の終わりに、「到達チェック」があります。何も見ずに、できるかどうかを、自分で確かめるものです。

- 「できること」の表で、検証の方法（テストが通る、手計算の値と一致する）で、確かめます
- 「時間を決めて書く課題」は、時間を計って、何も見ずに書きます
- できなかったときは、「誤りの原因の分類」の表で、原因（知らない・見抜けない・混同した・手順の誤り）を調べ、戻る章に戻ります

## 記号について {#symbols}

経済学の記号は、分野によって、同じ文字が別の意味になります。この記事でも、需要・供給の記号（a・b・c・d）と、マクロ経済学の記号（限界消費性向の c など）が、同じ文字を使います。章を読むときは、**その章の「式とコードの対応」の表**を、基準にしてください。意味が変わる章には、表の下に、注記があります。

### 全章に共通する記号

| 記号 | 意味 |
| :--- | :--- |
| P | 価格（第 13 章以降は、物価水準） |
| Q | 数量（第 10 章では、産出量） |
| q | 企業 1 社の生産量（Q は、市場全体の数量） |
| Y | 国民所得（第 9・13・14 章） |

### 需要・供給の係数（第 1・3・6・7・9・15 章）

需要曲線を Q = a − bP、供給曲線を Q = c + dP と書きます。

| 記号 | 意味 |
| :--- | :--- |
| a | 需要曲線の切片（価格が 0 のときの需要量） |
| b | 需要曲線の傾き（価格が 1 上がると減る量） |
| c | 供給曲線の切片（価格が 0 のときの供給量） |
| d | 供給曲線の傾き（価格が 1 上がると増える量） |

### 章によって意味が変わる記号

| 記号 | 意味（章） |
| :--- | :--- |
| a | 需要曲線の切片（第 1・3・6・7・9・15 章）／フィリップス曲線の傾き（第 14 章） |
| b | 需要曲線の傾き（第 1・3・6・7・9・15 章）／投資の利子率感応度（第 13 章） |
| c | 供給曲線の切片（第 3・6・7・9 章の均衡、第 15 章）／**限界消費性向**（第 9 章の乗数と 45 度線分析、第 13 章） |
| k | 調整の速さ（第 5 章）／貨幣需要の所得感応度（第 13 章）／オークンの法則の係数（第 14 章） |
| r | 資本の価格（第 10 章）／利子率（第 13・14 章） |
| L | 労働量（第 10 章）／貨幣需要（第 13 章） |
| C | 総費用（第 4 章）／消費（第 9・13 章） |
| A | 利子率や所得に依存しない支出（第 13 章）／逆需要曲線の切片 A = a ÷ b（第 15 章） |
| n | 観測値・標本の大きさ（第 8 章）／企業の数（第 15 章） |
| t・T | t: 1 単位あたりの税額（第 7・15 章）、税率（第 9 章の練習問題）／T: 定額税（第 13 章） |
| P | 個別の財の価格（第 1〜12 章）／物価水準（第 13・14 章） |

### 1 つの章で使う、そのほかの記号

| 記号 | 意味（章） |
| :--- | :--- |
| α | コブ・ダグラス型の指数（第 4・10 章） |
| w、K、m | 賃金、資本量、消費者の所得（予算）（第 10 章） |
| C0、I、I0、G、M、h | 基礎消費、投資、利子率が 0 のときの投資、政府支出、貨幣供給、貨幣需要の利子率感応度（第 9・13 章） |
| σ、ε | 需要のばらつきの標準偏差、ばらつきの項（第 8 章） |
| B | 1 ÷ b（逆需要曲線 P = A − B·Q の傾き）（第 15 章） |
| e | 1 単位あたりの外部費用（第 15 章） |
| π、u、u_n、V | 物価上昇率、失業率、自然失業率、貨幣の流通速度（第 14 章） |
