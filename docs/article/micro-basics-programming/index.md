# ミクロ経済学のためのプログラミング（初級）

教科書的なミクロ経済学（消費者行動、企業行動、市場均衡、不完全競争と市場の失敗）を、Python のコードとテストで学ぶ記事シリーズです。無差別曲線・費用曲線・需給曲線・余剰の式を関数にして、手計算の値と、モデルの性質（最適点では限界代替率 = 価格比、均衡で総余剰が最大、など）を、テストで確かめます。

第 1 シリーズと題材が重なる章がありますが、各章は、**この連載だけで独立して読めます**（必要な前提は、各章の冒頭に表で示します）。

この連載の**範囲**は、教科書の静学モデル（効用最大化・費用最小化・市場均衡・余剰・不完全競争・市場の失敗）を、関数とテストにして、比較静学を行うところまでです。実際の統計データ、動学、ゲーム理論の発展的な内容は、扱いません。

### 進め方

1. **予想する**: コードを見る前に、紙で、手計算の答えを予想します。**答えは書いてありません。**
2. **自分で書く**: `practice/` に、テストを先に書いて、実装を書きます（Red → Green → Refactor）
3. **答え合わせ**: 「プログラミング」の節の小節「予想の答え合わせ」で、予想の答えを、プログラムを動かして確かめます。完成形（`lib/` と `test/`）とも、見比べます
4. **練習問題・振り返り**: 条件を変えて試します。解答は、各章の練習問題の下に、折りたたんで置いてあります。先に自分で取り組んでから、開いてください
