    コードレビュー結果¶

    レビュー対象¶

    • 実装: apps/econometrics-programming/python/（lib/chapter01〜16、test/、tools/、pyproject.toml、tox.ini）
    • 記事: docs/article/econometrics-programming/（index.md、how-to-read.md、第 1〜16 章）
    • CI: .github/workflows/python-ci.yml、mkdocs.yml
    • 時点: 第 4 部の完成直後（コミット 92e948d）。レビュー中に見つかった「コードフェンスの欠落」は、9669f1c で修正済み

    総合評価¶

    手計算・恒等式・外部ライブラリとの照合・種を固定したシミュレーションの 4 本柱が、実際に効いている。依存の向きは一方向で、循環はなく、3 シリーズの CI も通っている。一方、公開品質を損なう欠陥が 1 件（コードがフェンスの外にあった）あり、修正した。残る主な課題は 3 つ。(1) 数値の安定性（第 14・16 章の確率の比）、(2) 記事の説明の誤りと再現性（第 6・15 章）、(3) 3 シリーズに複製された tools/ のずれ。

    • 依存は、後の章から前の章への一方向だけで、循環がない。lib/ は statsmodels・linearmodels を import せず、照合にだけ使う
    • 乱数は全章で rng を引数に受け取る。第 15 章の解析的な勾配は、4 本とも正しい
    • スケール（x を 1000 倍、y を 1/1000）と、まれな事象（y = 1 が 7 件）でも、第 14・15 章の結果は statsmodels と一致した。第 15・16 章の SE と実際のばらつきの比は、種を変えても 0.88〜1.07
    • 実データの節は、出典・件数・「利用条件は確認していません」を正直に書き、「言えること／言えないこと」を毎回書き分けている
    • 利用者代表が、スクラッチ領域で、uv sync から uv run pytest（393 passed）と、第 6・10・13・16 章の実データのスクリプトまで再現し、記事の出力と完全に一致した
