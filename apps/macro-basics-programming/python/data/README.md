この記事で使うデータです。

## ch03_indicators.csv（第 3 章）

**架空の**月次指標です。実在の統計では、ありません。景気動向指数（DI・CI）の計算を、確かめるために、作りました。

| 列 | 意味 |
| :--- | :--- |
| `month` | 月（`2025-01` 〜 `2025-12` の 12 か月。行の名前になる） |
| `production` | 生産指数（架空。2025 年 1 月 = 100） |
| `retail_sales` | 商業販売額（架空。単位は億円） |
| `job_openings_ratio` | 有効求人倍率（架空。倍） |
| `income` | 所得（架空。単位は億円） |

- 作り方: 1〜6 月に上昇し、7〜10 月に低下し、11〜12 月に再び上昇する、1 つの景気循環の形に、手で作りました。欠損は、ありません
- 使い方: `lib/chapter03/indicators.py` の `load_indicators` で読み込みます。`diffusion_index`（DI）と `composite_index`（CI）に、渡します
