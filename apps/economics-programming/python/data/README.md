# データ

## economy.csv

第 11・12 章で使う、**架空の国**のマクロ統計（2010〜2021 年、12 年分）です。実在の国・年の統計ではありません。単位は兆円です。

構造は、実際の統計（国民経済計算）に合わせています。生産・分配・支出の 3 面と、統計上の不突合、GDP デフレーターを持ちます。

| 列 | 意味 |
| :--- | :--- |
| `year` | 年 |
| `primary`・`secondary`・`tertiary` | 第 1 次・第 2 次・第 3 次産業の付加価値（生産面） |
| `wages`・`profits`・`depreciation_and_tax` | 雇用者報酬・営業余剰・固定資本減耗と間接税（分配面） |
| `consumption`・`investment`・`government`・`exports`・`imports` | 消費・投資・政府支出・輸出・輸入（支出面） |
| `deflator` | GDP デフレーター（2015 年 = 100） |

生産面と分配面の合計は、全年で一致します。支出面の合計は、輸入に年ごとの小さな誤差を入れてあり、生産面との差が「統計上の不突合」になります。

## 実際の統計で試す（内閣府の国民経済計算）

架空のデータに加えて、内閣府の国民経済計算（暦年）の CSV を、同じ形の表に直して読めます（`lib/chapter11/sna.py`）。手順と結果の例は、第 11 章の「実際の統計で試す」にあります。

1. 内閣府・経済社会総合研究所の「四半期別 GDP 速報」の統計表一覧から、「国内総生産(支出側)及び各需要項目」の「名目暦年」（例: `gaku-mcy2611.csv`）と、「暦年デフレーター」（例: `def-cy2611.csv`）を保存する
2. `load_sna_expenditure(名目の CSV, デフレーターの CSV)` で読む

CSV の形は、次のとおりです（読み込む関数が、これを前提にしています）。

| 項目 | 内容 |
| :--- | :--- |
| 文字コード | cp932 |
| 見出し | 先頭の 7 行 |
| 年の行 | `2020/1-12.` の形 |
| 金額の単位 | 10 億円（表は、兆円に直す） |
| デフレーターの基準 | 2020 年 = 100 |

実際の統計の CSV は、リポジトリに入れていません（公表のたびに改定されるため、各自が取得します）。各統計の利用条件を確認し、出典（公表の回と取得日）を明記してください。生産面・分配面の列は、この表にないので、`production_gdp` などは使えません。
