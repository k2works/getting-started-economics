# practice

記事「経済学のためのプログラミング入門」を読みながら、**自分でコードを書く場所**です。

- 章ごとに、`practice/chapterNN/` を作り、その中に、テスト（`test_*.py`）と実装（`*.py`）を置きます。
- ファイル名は、完成形（`lib/chapterNN/` と `test/chapterNN/`）と同じにすると、答え合わせがしやすくなります。
- テストの実行: `uv run pytest practice/chapter01`
- 完成形の `lib/` と `test/` は、答え合わせ用です。自分のコードを書き終えてから、開いてください。

このディレクトリに作ったファイルは、Git の管理から外れています（この `README.md` だけが管理の対象です）。
