# データ

## countries.csv

第 1 章で使う、**架空の 24 か国**の、労働者 1 人当たりの所得・物的資本・人的資本です。実在の国・年の統計ではありません。単位は、架空のものです。

| 列 | 意味 |
| :--- | :--- |
| `country` | 国名（C01〜C24。所得の高い順） |
| `y` | 労働者 1 人当たりの所得 |
| `k` | 労働者 1 人当たりの物的資本 |
| `h` | 人的資本（労働者の技能の水準） |

生産関数 y = A · k^(1/3) · h^(2/3) を、（小数第 3 位までの丸めを除いて）満たすように作りました。共通の「発展の度合い」z（標準正規乱数、種 0）が、ln k・ln h・ln A を、そろって高くする設定です（ln k = 2.0 + 1.0·z + 0.3·ε、ln h = 0.5 + 0.25·z + 0.1·ε、ln A = 0.6·z + 0.3·ε。ε は、独立な標準正規乱数）。CSV の値が正で、データの出典です。

## panel.csv

第 2 章で使う、同じ**架空の 24 か国**の、1990〜2019 年の年次パネルです（24 か国 × 30 年 = 720 行）。実在の国・年の統計ではありません。

| 列 | 意味 |
| :--- | :--- |
| `country` | 国名（`countries.csv` と同じ C01〜C24） |
| `year` | 年（1990〜2019） |
| `y`・`k`・`h` | 労働者 1 人当たりの所得・物的資本・人的資本（`countries.csv` と同じ意味） |

2019 年の値は、`countries.csv` と同じです。それ以前は、国ごとの成長率で遡って作りました。「発展の度合い」z（`countries.csv` を作ったときと同じ乱数）が低い国ほど、成長が速くなる設定です（1 年当たりの対数の成長率: g_A = 0.012 − 0.004·z + 0.004·ε、g_k = 0.030 − 0.006·z + 0.008·ε、g_h = 0.008 − 0.001·z + 0.002·ε。ε は、独立な標準正規乱数、種 1）。年ごとに、小さなゆらぎ（k に 0.01、h に 0.003、A に 0.02 の標準偏差）を足しています。生産関数 y = A·k^(1/3)·h^(2/3) を満たします。

## prices.csv

第 7 章で使う、**架空の 20 か国**の、同じ商品の価格・為替レート・1 人当たりの所得です（実在の国・商品の値ではありません）。

| 列 | 意味 |
| :--- | :--- |
| `country` | 基準の国 `BASE`（価格 5.0、為替レート 1、所得 65,000）と、D01〜D19（所得の高い順） |
| `local_price` | 自国通貨での、同じ商品の価格 |
| `exchange_rate` | 為替レート（自国通貨 / ドル） |
| `income` | 1 人当たりの所得（ドル） |

相対価格水準が (所得 ÷ 65,000)^0.25 に、小さなゆらぎ（対数の標準偏差 0.12）を掛けた値になるように作りました（ペン効果の傾きの真の値が 0.25）。所得は対数正規乱数（種 2）、為替レートは 1.5〜300 の対数一様乱数です。

## 実際の統計で試す（Penn World Table）

第 7 章の 7.5 節で、実際の国際比較データ **Penn World Table 10.01** を、第 1〜6 章の関数で分析します。

1. [GGDC のページ](https://www.rug.nl/ggdc/productivity/pwt/pwt-releases/pwt1001)（DOI: 10.34894/QT5BCC）から、Stata 形式の `pwt1001.dta` を取得して、このディレクトリ（`data/`）に置く
2. `load_pwt(Path("data/pwt1001.dta"))` で読む（`lib/chapter07/pwt.py`）
