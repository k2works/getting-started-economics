# データ

## countries.csv

第 1 章で使う、**架空の 24 か国**の、労働者 1 人当たりの所得・物的資本・人的資本です。実在の国・年の統計ではありません。単位は、架空のものです。

| 列 | 意味 |
| :--- | :--- |
| `country` | 国名（C01〜C24。所得の高い順） |
| `y` | 労働者 1 人当たりの所得 |
| `k` | 労働者 1 人当たりの物的資本 |
| `h` | 人的資本（労働者の技能の水準） |

生産関数 y = A · k^(1/3) · h^(2/3) を、（小数第 3 位までの丸めを除いて）満たすように作りました。共通の「発展の度合い」z（標準正規乱数、種 0）が、ln k・ln h・ln A を、そろって高くする設定です（ln k = 2.0 + 1.0·z + 0.3·ε、ln h = 0.5 + 0.25·z + 0.1·ε、ln A = 0.6·z + 0.3·ε。ε は、独立な標準正規乱数）。CSV の値が正で、データの出典です。

## 実際の統計で試す

実際の統計（Penn World Table など）で試す手順は、第 7 章（第 1 部の終わり）で扱う予定です。各統計の利用条件を確認し、出典（公表の回と取得日）を明記してください。
