# データ

## countries.csv

第 1 章で使う、**架空の 24 か国**の、労働者 1 人当たりの所得・物的資本・人的資本です。実在の国・年の統計ではありません。単位は、架空のものです。

| 列 | 意味 |
| :--- | :--- |
| `country` | 国名（C01〜C24。所得の高い順） |
| `y` | 労働者 1 人当たりの所得 |
| `k` | 労働者 1 人当たりの物的資本 |
| `h` | 人的資本（労働者の技能の水準） |

生産関数 y = A · k^(1/3) · h^(2/3) を、（小数第 3 位までの丸めを除いて）満たすように作りました。共通の「発展の度合い」z（標準正規乱数、種 0）が、ln k・ln h・ln A を、そろって高くする設定です（ln k = 2.0 + 1.0·z + 0.3·ε、ln h = 0.5 + 0.25·z + 0.1·ε、ln A = 0.6·z + 0.3·ε。ε は、独立な標準正規乱数）。CSV の値が正で、データの出典です。

## panel.csv

第 2 章で使う、同じ**架空の 24 か国**の、1990〜2019 年の年次パネルです（24 か国 × 30 年 = 720 行）。実在の国・年の統計ではありません。

| 列 | 意味 |
| :--- | :--- |
| `country` | 国名（`countries.csv` と同じ C01〜C24） |
| `year` | 年（1990〜2019） |
| `y`・`k`・`h` | 労働者 1 人当たりの所得・物的資本・人的資本（`countries.csv` と同じ意味） |

2019 年の値は、`countries.csv` と同じです。それ以前は、国ごとの成長率で遡って作りました。「発展の度合い」z（`countries.csv` を作ったときと同じ乱数）が低い国ほど、成長が速くなる設定です（1 年当たりの対数の成長率: g_A = 0.012 − 0.004·z + 0.004·ε、g_k = 0.030 − 0.006·z + 0.008·ε、g_h = 0.008 − 0.001·z + 0.002·ε。ε は、独立な標準正規乱数、種 1）。年ごとに、小さなゆらぎ（k に 0.01、h に 0.003、A に 0.02 の標準偏差）を足しています。生産関数 y = A·k^(1/3)·h^(2/3) を満たします。

## quarterly.csv

第 8〜10 章で使う、**架空の国**の四半期のマクロ時系列です（1980Q1〜2019Q4、160 四半期）。実在の統計ではありません。

| 列 | 意味 |
| :--- | :--- |
| `year`・`quarter` | 年・四半期 |
| `gdp`・`consumption`・`investment` | 実質 GDP・消費・投資（水準） |
| `unemployment` | 失業率（%） |
| `inflation` | 物価上昇率（年率 %） |

景気循環 c(t) は AR(1)（ρ = 0.85、ショックの標準偏差 0.8%、種 3）で、トレンドは毎四半期 0.5% の直線です。ln GDP = ln 100 + 0.005·t + c、ln 消費 = ln 60 + 0.005·t + 0.7·c + 小さな誤差（0.3%）、ln 投資 = ln 20 + 0.005·t + 3·c + 誤差（2%）。失業率は、オークンの法則 u = 4 − 0.5·(100·c) + 誤差（0.15）、物価上昇率は、フィリップス曲線 π = 2 − 傾き·(u − 4) + 誤差（0.25）で、傾きは、1999 年（80 四半期目）より前が 0.5、以降が 0.2 です。

## prices.csv

第 7 章で使う、**架空の 20 か国**の、同じ商品の価格・為替レート・1 人当たりの所得です（実在の国・商品の値ではありません）。

| 列 | 意味 |
| :--- | :--- |
| `country` | 基準の国 `BASE`（価格 5.0、為替レート 1、所得 65,000）と、D01〜D19（所得の高い順） |
| `local_price` | 自国通貨での、同じ商品の価格 |
| `exchange_rate` | 為替レート（自国通貨 / ドル） |
| `income` | 1 人当たりの所得（ドル） |

相対価格水準が (所得 ÷ 65,000)^0.25 に、小さなゆらぎ（対数の標準偏差 0.12）を掛けた値になるように作りました（ペン効果の傾きの真の値が 0.25）。所得は対数正規乱数（種 2）、為替レートは 1.5〜300 の対数一様乱数です。

## money_panel.csv

第 11・12 章で使う、**架空の 20 か国**（E01〜E20）の、1990〜2019 年の貨幣の伸び率・実質成長率・物価上昇率です（実在の国の値ではありません）。

| 列 | 意味 |
| :--- | :--- |
| `country` | 国（E01〜E20） |
| `year` | 年 |
| `money_growth` | 貨幣の伸び率（% / 年） |
| `real_growth` | 実質成長率（% / 年。貨幣の伸び率とは無関係に作った） |
| `inflation` | 物価上昇率（% / 年）= 貨幣の伸び率 − 実質成長率 + 誤差（誤差の大きさは貨幣の伸び率に応じて大きい） |

E19 の 1992〜1995 年と E20 の 2008〜2010 年に、ハイパーインフレ（貨幣の伸び率が 100% 超）の期間があります（計 7 行）。乱数の種は 4 です。

## adas_quarterly.csv

第 13・14 章で使う、**架空の**四半期データ（1980Q1〜2019Q4、160 四半期）です。**真のパラメーターを知っている**動学的 AD-AS モデルから作りました（実在の経済の値ではありません）。

| 列 | 意味 |
| :--- | :--- |
| `year`・`quarter` | 年・四半期 |
| `gdp` | GDP の水準（ln GDP = ln 100 + 0.005·t + y ÷ 100） |
| `deflator` | デフレーターの水準（ln P = ln 100 + 0.004·t + p ÷ 100） |

y と p は、モデル p(t) = h·p(t−1) + h·(a·u + v)、y(t) = −c·h·p(t−1) + h·(u − c·v) から作った、トレンドからの乖離（%）です。真のパラメーターは、a = 0.8、c = 0.3（h = 0.806）、σu = 1.5、σv = 1.2、乱数の種は 6 です。
