# データ

## economy.csv

第 11・12 章で使う、**架空の国**のマクロ統計（2010〜2021 年、12 年分）です。実在の国・年の統計ではありません。単位は兆円です。

構造は、実際の統計（国民経済計算）に合わせています。生産・分配・支出の 3 面と、統計上の不突合、GDP デフレーターを持ちます。

| 列 | 意味 |
| :--- | :--- |
| `year` | 年 |
| `primary`・`secondary`・`tertiary` | 第 1 次・第 2 次・第 3 次産業の付加価値（生産面） |
| `wages`・`profits`・`depreciation_and_tax` | 雇用者報酬・営業余剰・固定資本減耗と間接税（分配面） |
| `consumption`・`investment`・`government`・`exports`・`imports` | 消費・投資・政府支出・輸出・輸入（支出面） |
| `deflator` | GDP デフレーター（2015 年 = 100） |

生産面と分配面の合計は、全年で一致します。支出面の合計は、輸入に年ごとの小さな誤差を入れてあり、生産面との差が「統計上の不突合」になります。

## 実際の統計に置き換える

同じ列の形に整えれば、実際の公開統計（内閣府の国民経済計算など）でも、第 11・12 章の関数がそのまま使えます。各統計の利用条件を確認し、出典を明記してください。
