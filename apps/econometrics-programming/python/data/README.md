# データ

この記事のデータは、主に、**乱数で作る**ものです。母集団の式（真の係数）を、自分で決めて、データを作ります（作り方は、各章の本文にあります）。そのため、このディレクトリには、現時点で、データのファイルはありません。

## 実際のデータ

各部の終わりの「実際のデータで試す」手順では、`wooldridge` パッケージ（MIT ライセンス）のデータを使います。

- データは、パッケージから、各自の手元に取り込みます。**リポジトリには入れません**
- データそのものは、教科書（Wooldridge, *Introductory Econometrics: A Modern Approach*、Cengage）のものです。利用条件は、各自で確認し、使うときは、出典を明記してください
