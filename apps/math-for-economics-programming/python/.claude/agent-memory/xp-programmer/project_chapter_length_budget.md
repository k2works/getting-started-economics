連載「経済学で出る数学プログラミング」は、1 章 600 行が目安だが、実測は第 1 章 840 行、第 3 章 913 行（2026-11-22、Bolt 1）。

**Why:** 読者の `N passed` を合わせるため、テストを 1 件残らず記事に転記する規則がある。第 3 章では、コードの転記（テスト約 250 行・実装 135 行・import）が記事の約半分を占めた。重複テストを統合して 1021 → 913 行に減らしたのが限界だった。

**How to apply:** 章の見積もりでは、テスト関数の数を最初から絞る（境界値は 1 つのテストに複数の assert でまとめる、parametrize で組を並べる）。行数の目安を守るには、統合担当に「目安を 900 行に上げる」か「境界のテストを記事に載せない代わりに件数の表示を分ける」かの判断を仰ぐ。[[math03-design-notes]]
