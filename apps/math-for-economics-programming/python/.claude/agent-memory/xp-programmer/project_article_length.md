記事（docs/article/math-for-economics-programming/NN-*.md）は、テスト件数を写経結果と合わせるため、全テストを本文か折りたたみに転記する。そのため行数の大半はテストのコード（第 2 章で初稿 892 行中 539 行がコード）。

**Why:** 目安 600 行に対し、第 1 章 840 行、第 2 章も初稿 892 行 → 同じ概念の小テストを 1 関数にまとめて 843 行（テスト 55 → 45 件、変異の検出力は同じ）。

**How to apply:** 章の実装時から、1 つの概念（判別式の 3 つの場合、最適反応の各点など）は 1 テストに複数 assert でまとめる。境界のテストも parametrize でまとめる。それでも 600 行は、テスト全件転記の制約と両立しにくいので、超過は報告する。

第 5 章（2 モジュール＋図 2 点、テスト 45 件）は、折りたたみを使っても 986 行。行数を決めるのは「転記する定義の数」で、描画テストを概念ごとに 1 つへまとめる（5 → 3 件）・描画の実装を「ラベルと関数の組」のループにする、が効いた。テンプレートの `{{path:A}}` は名前 1 つだけを取り出すので、定数を複数使うテストでは `{{path:A, B, C}}` と全部書く（漏れても check_articles は気づかない）。

第 6 章（3 モジュール＋図 2 点、テスト 51 件）は 1010 行（折りたたみ約 290 行、見える部分は約 720 行）。予想の答え合わせのスクリプトに、空行 2 つで区切ったトップレベルの `def` を書くと、check_articles が「ソースにないコード」と判定する（`def`・`class`・大文字の定数が対象）。`functools.partial` や lambda で避ける。答え合わせのスクリプトは、テンプレートの python ブロックから正規表現で取り出して実行すると、テンプレートとずれない（SP/build_math06.py）。

第 8 章（2 モジュール＋図 2 点、テスト 54 件）は 1348 行（折りたたみ: 図 約 250・発展 約 120・境界 約 100 行）。「図を後回しにするならテストは N 件」の N は `--deselect test_plot.py` で数えるので、**図の折りたたみには test_plot.py のテストと plot.py だけを置く**（図で使う lib の関数とそのテストは、本文に置く。置き場所がずれると、図を飛ばした読者の件数が合わない）。
