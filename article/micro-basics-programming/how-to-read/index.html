    この記事の読み方¶

    この記事は、教科書的なミクロ経済学の式とグラフを、Python の関数とテストで確かめながら、学ぶ構成です。全章は、同じ型で書いてあります。型を知っておくと、どの章でも、迷わずに進められます。

    準備（uv のインストールなど）は、第 1 シリーズの第 1 章 の 1.2 節にあります。

    章の型¶

    どの章も、次の順で進みます。

    節 やること ねらい
    この章の地図 題材、使う機能、完成形のファイル、経済学の式とコードの対応を、先に見る。図を 1 点、先に見る 全体像を先に持つと、細部が既知の知識とつながる
    予想する コードを見る前に、手計算で、結果を予想する（紙に書く）。答えは書いていない 先に自分で考えると、答えが長く記憶に残る
    概念の説明 その章で使う経済学の用語と、ライブラリの機能を学ぶ 必要な知識を、必要なときに
    プログラミング practice/ に、テストを先に書き、失敗を確かめ、最小の実装で通し、整える。最後に、小節「予想の答え合わせ」で、予想の答えを、プログラムで確かめる 式をコードにする型を、手で覚える
    規則で言うと その章の原則を 2〜3 個にまとめる。混同しやすい点を表で比べ、「このモデルが成り立たない場面」を確かめる 個々の知識を、使える構造にする
    練習問題 想起・生成・多様・交互の 4 問。解答は、問題の下に折りたたんである 本文を見ずに書く、条件を変える、前の章と混ぜる
    振り返り うまくいった所、詰まった所、次に試すことを、ノートに書く 自分の理解の穴を見つける
    まとめ その章で学んだことの確認と、次の章の予告 —

    予想の答え合わせ¶

    「予想する」の節には、答えを書いていません。 答えは、「プログラミング」の節の小節「予想の答え合わせ」で、スクリプトを動かした出力として示します。スクリプトは、その章の関数を呼ぶだけの短いものです。まず自分の予想を紙に書き、そのあとで、出力と見比べてください。

    練習問題と解答¶

    種類 内容
    想起 本文を閉じて、その章の関数を、自分で書く
    生成 解説を見る前に、新しい関数を、テストから書く
    多様 数値や式（パラメーター）を変えて、結果がどう変わるかを、先に予想してから確かめる
    交互 前の章の道具や、第 1 シリーズの内容と、組み合わせる

    解答（コードと手計算の答え）は、各章の練習問題の下に、折りたたんであります。先に自分で取り組んでから、開いてください。

    到達チェック¶

    第 1 部（第 4 章）、第 2 部（第 7 章）、第 3 部（第 10 章）、第 4 部（第 14 章）の終わりに、「到達チェック」があります。何も見ずに、できるかどうかを、自分で確かめる節です。先に「何も見ずに書く課題」を試し、そのあとで、答えの表を見てください。 できなかった項目は、戻る章が書いてあります。

    データについて¶

    この記事は、データを使いません。 実在の統計も、架空の表形式のデータも、使いません。手計算できる小さな例だけを、本文とテストに書きます（利用条件の問題と、取得の手間を避けるため）。

    記号について¶

    経済学の記号は、分野によって、同じ文字が別の意味になります。章を読むときは、その章の「式とコードの対応」の表を、基準にしてください。意味が変わる章には、表の下に、注記があります。

    全章に共通する記号¶

    記号 意味
    x・y 2 つの財の量（第 1〜4 章。消費者行動）
    U 効用（第 1 章以降）。効用の値は、順序だけに意味がある
    MRS 限界代替率（第 1 章）。財 y で測った、財 x の価値
    P・Q 価格・数量（第 8 章以降の市場）

    章によって意味が変わる記号¶

    章を書き進めるたびに、この表に足します。

    記号 意味（章）
    a・b 効用のべき指数（第 1〜4 章。U = x^a · y^b）。第 5 章以降の費用関数の係数とは別
    m 所得（第 2〜4 章。予算線 Px·x + Py·y = m）。第 1 部だけの記号
    e 弾力性（第 3 章。価格弾力性・所得弾力性）
    Px・Py 財 x・財 y の価格（第 2〜4 章）。第 8 章以降の市場の価格 P とは別
    代替効果・所得効果 財 x の量の変化（第 4 章。値下げのときの符号で書く。値上げでは逆）

    分量と進め方の目安¶

    1 章は、読むだけなら 1〜2 時間ですが、手を動かすと、章によっては 1 回では終わりません。各章の「図」の小節（描画のテストと実装）は、折りたたんであり、後回しにしても、学習は成り立ちます。

    環境について¶

    uv sync は、兄弟のディレクトリ apps/article-tools/（記事の検査ツール）に依存します。アプリのフォルダだけを取り出さず、リポジトリごと使ってください。

    完成形の使い方¶

    サンプルコードには、各章の完成形が入っています（lib/ と test/）。答え合わせ用です。自分のコードを、practice/ に書いてから、見比べてください。

    写経の手順（import と実行）¶

    • テストの import は、完成形では from lib.chapter01.utility import ... です。自分で書くときは、from practice.chapter01.utility import ... に書き換えます。書き換えないと、完成形を読み込んで、最初から通ってしまい、Red になりません
    • 前の章の関数（例: 第 2 章が使う lib.chapter01）は、完成形の lib から import してかまいません。同じ章の中だけを、自作にします。入力の検証の共通関数（validate_positive・validate_non_negative）も、lib/chapter01/validation.py から import します
    • 記事のコードの抜粋には、import 行と、先頭が _ の補助関数（入力の検証など）を、省いた箇所があります。写すときは、lib/chapterNN/ の該当ファイルの先頭を、見て、足してください
    • 「予想の答え合わせ」のスクリプトは、practice/chapterNN/check.py に保存し、apps/micro-basics-programming/python で uv run python -m practice.chapterNN.check と実行します（from lib... が通るのは、このディレクトリで実行したときだけです）

    参考にした資料¶

    この記事の章立てと、式・数値の例は、このリポジトリの 経済学・経済政策 トピック別マインドマップ と 全体マインドマップ に基づきます。外部の教材・データは、参照していません。
